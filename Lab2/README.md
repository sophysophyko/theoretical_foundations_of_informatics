## Краткое описание задачи
Консольная программа на базовом Python для чтения, проверки, обработки и анализа заказов магазина из текстового файла, а также формирования итогового отчёта.

## Формат входного файла
Входной файл `orders.txt` содержит записи о заказах в формате:
`номер; покупатель; категория; количество; цена; статус`

Допустимые статусы: `новый`, `в обработке`, `выполнен`, `отменён`.

## Инструкция по запуску
Убедитесь, что файл `orders.txt` находится в одной папке с `main.py`, и запустите программу командой:
```bash
python main.py
```

## Описание структуры программы
- `main.py` — исходный код программы (чтение и разбор строк, валидация, фильтрация, поиск, сортировка, расчёт статистики, вывод в консоль, сохранение отчёта, автоматические проверки `assert` и меню).
- `orders.txt` — входной файл с тестовыми данными (корректные и ошибочные записи).
- `orders_report.txt` — формируемый итоговый отчёт.
- `README.md` — описание лабораторной работы.

## Перечень основных возможностей
1. Вывод всех корректных заказов с расчётом стоимости и категории стоимости (`Малый`, `Средний`, `Крупный`).
2. Сортировка заказов по убыванию стоимости (при равенстве — по возрастанию номера) и по категории и имени покупателя.
3. Фильтрация по статусу и по категории товара без учёта регистра.
4. Поиск заказов по части имени покупателя.
5. Отбор крупных заказов (стоимость от 5000).
6. Расчёт общих показателей, статистики по категориям и по статусам.
7. Сохранение полного отчёта в файл `orders_report.txt`.

## Примеры корректной и некорректной записи
- **Корректная запись:**
  `1001; Иванов Иван; Книги; 2; 750.50; выполнен`
- **Некорректные записи:**
  - `1024; Фёдоров Фёдор; Книги; 0; 500.00; выполнен` (неположительное количество)
  - `1027; Сергеев Сергей; Канцелярия; 2; 300.00` (неверное количество полей)
  - `1029; Никитин Никита; Книги; 1; 350.00; доставляется` (неизвестный статус)

## Перечень обработанных ошибок
1. Отсутствие входного файла `orders.txt`.
2. Неправильное количество полей в строке (не равно 6).
3. Невозможность преобразования номера заказа, количества или цены в число.
4. Неположительные значения номера заказа, количества или цены.
5. Повторяющийся номер заказа.
6. Пустое имя покупателя или пустая категория товара.
7. Неизвестный статус заказа.
8. Ввод неизвестного пункта консольного меню.
9. Отсутствие результатов поиска или фильтрации.
10. Отсутствие корректных записей и расчёт показателей для пустого списка.
